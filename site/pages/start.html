Get started

Four steps. About ten minutes.

You need a computer and the TV on the same network. Nothing on the TV changes until you say yes.

  1. Turn on ADB debugging

    On the TV: Settings → My Fire TV → About, press OK on the device name 7 times, then Settings → My Fire TV → Developer Options → ADB debugging.

  2. Find the TV's IP address

    Settings → My Fire TV → About → Network. It looks like 192.168.x.x.

  3. Install adb and get dontv

    Install Android platform-tools (it includes adb). On Windows, also install Git for Windows. Then:

    git clone https://github.com/don007shfx/dontv.git
cd dontv

  4. Run it

    macOS and Linux

    adb connect <tv-ip>:5555        # press Allow on the TV
./scripts/preflight.sh          # what the TV is and what would change; changes nothing
./scripts/configure.sh          # a few questions
./scripts/all.sh --dry-run      # every command the pass would send; changes nothing
./scripts/all.sh                # asks before each step, reboots the TV twice
./scripts/verify.sh             # checks the result
./scripts/health.sh             # memory, storage, launcher, VPN; changes nothing

    Windows

    The wrapper runs the same scripts through Git Bash, so you don't have to open it. Run these from the dontv folder in Command Prompt or PowerShell:

    adb connect <tv-ip>:5555
windows\dumbtv preflight
windows\dumbtv configure
windows\dumbtv all --dry-run
windows\dumbtv all
windows\dumbtv verify

    The wrapper keeps its original name, dumbtv, so the commands match the files in the repository. More on Windows.

    Or ask a coding agent

    Open Claude Code, Codex, Cursor, Gemini or similar in the dontv folder and say: "Clean up my Fire TV. Its IP address is …". It follows the repository's AGENTS.md and asks before changing anything.

What it asks you

configure.sh questions. Answers are saved in dumbtv.conf.
QuestionDefault
Do you watch Prime Video?yes: its servers stay reachable
Keep Alexa and the voice button?yes
Replace Amazon's home screen?yes
Open Projectivy Launcher instead of dontv home? Both stay installed.no: dontv home
Run the DNS filter on the TV?yes; skipped when Proton VPN or another VPN app is on the TV
Replace the YouTube app with SmartTube?no
Match the TV's output to each video's frame rate?no
Also turn off the generic autoplay settings on Amazon's home?no
Any apps you want removed?none

Every script that changes the TV takes --dry-run and asks before its first change. preflight.sh, verify.sh, health.sh and switch-home.sh status never change anything.

Undo it all

./scripts/restore.sh          # Windows: windows\dumbtv restore
