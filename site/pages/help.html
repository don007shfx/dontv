Help

Help and FAQ.

Most problems are fixed by one of the commands below. On Windows, use windows\dumbtv <name> instead of ./scripts/<name>.sh.

How do I undo everything?

./scripts/restore.sh

It turns every package back on, clears the app and network rules, puts back the settings your TV had before (saved by preflight.sh), switches off the DNS filter and gives HOME back to Amazon. Optional settings such as frame-rate matching go back to the TV's own values. Apps you asked to have uninstalled come back from the Appstore.

How do I check it is still working?

./scripts/health.sh     # read-only: memory, storage, home screen, VPN
./scripts/verify.sh     # pass/fail checks

health.sh changes nothing. It shows free memory and storage, which home screen catches HOME, who holds the VPN, settings that drifted, and any package a Fire OS update switched back on. If something came back, run ./scripts/all.sh again.

I use Proton VPN. Will they clash?

No. The DNS filter is itself a VPN, and Android runs only one at a time. If Proton VPN or another VPN app is installed, or an app holds always-on VPN, dontv skips the filter and tells you. Everything else still runs: packages are disabled, settings are changed and your launcher is set, and verify.sh skips the DNS checks. Without the filter, Amazon's telemetry and update servers are no longer blocked on the TV; a VPN with its own tracker blocking can cover part of that.

What does a factory reset do?

It removes everything dontv did, along with your apps and settings. Nothing is written to /system, so the TV comes back as new. Run the scripts again afterwards.

More questions

Does it need root? Can it brick my TV?

No root: everything runs as the shell user ADB gives you. The scripts never write to /system or touch the bootloader, and refuse to disable the home screen, Settings, inputs, remote pairing or Prime Video. The realistic worst case is a TV that boots to Amazon's home screen, which restore.sh or launcher.sh fixes.

Pressing HOME shows Amazon's home.

Run ./scripts/switch-home.sh status to see which launcher has HOME, then ./scripts/switch-home.sh dumbtv or projectivy to set it again.

How do I update Fire OS?

Updates are blocked while the DNS filter runs, because an update switches much of this back on. To update on purpose: ./scripts/restore.sh, let the TV update, then ./scripts/all.sh.

Will Prime Video, YouTube and the Appstore work?

Yes. Prime Video's servers stay reachable unless you say you don't watch it. YouTube and the Appstore are never blocked. YouTube's own ads come from the same servers as the videos, so DNS can't block them; SmartTube is offered as an option.

Does dontv phone home?

No. Your computer downloads personalDNSfilter, the launcher and the tracker list; nothing is uploaded. The launcher has no internet permission. This website has no cookies, analytics or tracking.
